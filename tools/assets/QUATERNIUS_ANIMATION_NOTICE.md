# Quaternius Universal Animation Library

The InBody web character and its local preview use the `Idle_Loop` animation from
Universal Animation Library **Standard v3.0**, published 16 June 2026.
Downloaded on 3 October 2026 from the creator, without registration/payment.
The character geometry remains the separate MPFB CC0 asset.

- Creator: Quaternius. The pack credits animator Gonzalo Furnier.
- [Official page](https://quaternius.com/packs/universalanimationlibrary.html)
- [Official download](https://quaternius.itch.io/universal-animation-library)
- [Animation viewer](https://quaternius.com/animviewer.html)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Archive: `Universal Animation Library[Standard].zip`
- Archive SHA-256: `cc73fc4e495b82958207316596317a3f40b9fa38065bde1027937452da537724`
- Source: `Unreal-Godot/UAL1_Standard.glb` (non-root-motion edition)
- Source SHA-256: `69591853d817488edaa8fd9bf8fc1d821eaeaf789f8627b3cd23b41c4ed67997`
- Clip: `Idle_Loop`, 2.5 seconds, 76 samples at 30 Hz.

Downloaded sources and intermediate resources stay under ignored
`runtime/inbody-character/`. The two retargeted clips ship as
`web/src/assets/body/male-idle.glb` and `female-idle.glb`. The exporter stores its
mapping and source hashes with the generated clip and production manifest.
Native source timing is retained; the application does not
claim that this keyframed game animation is a recording of a real performer.
